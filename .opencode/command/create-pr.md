---
description: Создаёт PR на основе коммитов текущей ветки
agent: build
---

Создай pull request для текущей ветки на основе её коммитов. Дополнительные
указания пользователя (если есть): $ARGUMENTS

1. Определи базовую ветку: используй `main`, если она существует; иначе ту,
   от которой фактически ответвилась текущая ветка.
2. Получи коммиты ветки: `git log <base>..HEAD` и `git diff <base>...HEAD --stat`.
3. Составь описание PR:
   - один коммит — заголовок PR равен заголовку коммита, тело берётся из него;
   - несколько коммитов — сводный заголовок в стиле Conventional Commits
     (`feat:`, `fix:` …) и тело со списком изменений по пунктам.
4. Если у ветки нет апстрима — запушь её: `git push -u origin HEAD`.
5. Создай PR: `gh pr create --base <base> --title <title> --body <body>`.

Правила:

- Не делай новых коммитов и не переписывай существующие.
- Не включай в PR несвязанные незакоммиченные изменения; если они есть,
  упомяни их в ответе, но в PR не добавляй.
- Если `gh` не установлен, не авторизован или это не GitHub-репозиторий —
  сообщи об этом и остановись.
- В конце выведи ссылку на созданный PR.
